What we make

Our first game is a machine you set off with one move.

Topple

A chain-reaction deduction puzzle for iOS and Android

Every level is a contraption waiting to go off — dominoes, rolling marbles and wooden deflectors, arranged so that exactly one opening move clears the board and every other move fails. There is no timer and there are no lives. The only question is which piece starts it.

Each of the 203 levels is machine-verified to have precisely one solution before a human ever sees it, then placed by hand into a difficulty curve. That combination — proved by a computer, arranged by a person — is the part we care most about getting right.
