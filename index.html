Topple

Chain reaction puzzle game

Each level is a board of dominoes and marbles, set up so one tap can knock the whole lot over. Only one piece starts the full chain, and the job is working out which one. There's no clock and no lives, so you can take as long as you need.

Every level is checked by computer to make sure there's exactly one answer, then put in order by hand so the difficulty builds up properly.
